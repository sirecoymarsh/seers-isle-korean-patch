# Seers Isle 한국어 번역 가이드

## 기본 방향

- 영어 `en-US`를 의미 원문으로 삼는다.
- 문학적 분위기는 살리되, 뜻을 흐리는 과도한 고어체는 피한다.
- 서술은 자연스러운 현재형을 기본으로 하고 원문의 시제 전환을 보존한다.
- 선택지는 행동 의도가 즉시 이해되도록 짧고 분명하게 쓴다.
- 인물의 감정과 관계를 주변 대사로 판단하며, 문장 하나만 떼어 기계적으로 번역하지 않는다.
- 원문에 없는 성별, 호칭, 인과관계, 감정을 새로 만들지 않는다.

## 표기와 형식

- 인용 부호는 `“ ”`를 유지한다.
- 말줄임표는 `…`로 통일한다.
- `<ok>`, `<log>`, `<pause>`, `<i>`, `</i>`, `{0}` 같은 태그와 변수는 정확히 보존한다.
- 키와 런타임 식별자는 번역하지 않는다.
- 줄바꿈은 원문의 의미 단위를 유지하되, 한국어 UI에서 읽기 편하게 배치한다.
- Twitch의 `twitch_command_original = choose`는 런타임 호환용 원문이므로 번역하지 않는다.

## 장·업적 표기

- `Chapter I` → `제1장`
- 장 제목은 `제1장 — “절벽”` 형식으로 쓴다.
- `Achievement unlocked:` → `업적 달성:`
- 업적명은 UI 제목과 해제 알림에서 철자와 띄어쓰기를 완전히 통일한다.

## 검토 기준

1. 같은 인물의 이름과 말투가 모든 분기에서 일치하는가?
2. 선택지와 뒤따르는 행동이 의미상 연결되는가?
3. 태그, 변수, 숫자, 고유명사가 보존됐는가?
4. 원문보다 의미가 강해지거나 약해지지 않았는가?
5. UI 문자열이 버튼과 패널 안에 들어갈 만큼 간결한가?
